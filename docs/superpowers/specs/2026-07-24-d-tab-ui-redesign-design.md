# 飞奕网关调试小程序 D 版改版设计

## 1. 目标与范围

将现有静态 HTML 原型直接覆盖为正式产品交付形态。保留“设备、工具、我的”三 Tab，以设备调试为核心，删除原型说明、演示提示、教学文字、过程注释、营销横幅及不在本次范围内的入口。

本次覆盖范围包括：

- 蓝牙设备发现、按型号聚合、展开设备及进入调试。
- E50 4G 远程设备列表和远程调试入口。
- A01、A02、A03、F16G、B25LG、FD01G、S74G、E50 的调试首页与更多设置。
- 工具页和我的页信息架构调整。
- 旧原型主要页面 URL 的兼容跳转。
- 产品外观图替换及移动端视觉统一。

不修改 `D:\workspace\E50小程序版 dev` 和产品资料源目录；所需图片复制到原型自身资源目录。

## 2. 产品与视觉原则

- 使用安静、克制、偏工程工具的正式交付风格，不使用营销型大图、渐变横幅或解释性卡片。
- 页面只保留标题、字段名、当前值、状态和可执行操作。必要错误反馈保持简短，不出现“演示环境”“请按以下步骤”等原型话术。
- 核心任务在首屏可见；低频参数统一进入“更多设置”。
- 延续飞奕蓝作为主操作色，卡片、列表和状态采用统一的间距、圆角和层级。
- 按 402 × 874 原型视口设计，同时适配常见移动端宽度和安全区。

## 3. 全局信息架构

### 3.1 设备 Tab

设备页顶部仅保留“蓝牙调试 / 4G 远程”分段切换。

蓝牙调试页结构：

1. 扫描状态与刷新操作。
2. 按型号聚合的产品卡片列表。
3. 点击产品卡片，在当前页面展开该型号搜索到的全部设备。
4. 点击具体设备，进入该型号快速配置首页。

产品卡片展示产品外观图、型号、产品类别、已发现设备数量和展开状态。设备行展示广播名、设备编号或 MAC、信号强度和连接操作。按 URL `model` 参数进入时，自动定位并展开对应型号，兼容旧型号入口。

4G 远程页只展示 E50 远程设备列表。每行包含设备名称、设备编号和在线状态；在线设备可直接进入 E50 远程调试，离线设备不可进入并仅显示“离线”。页面不提供绑定新设备、运行日志、顶部说明或其他型号入口。

### 3.2 工具 Tab

删除顶部介绍和说明文字，保留并重组为纯功能列表：

- 产品方案（原“产品手册”）
- 接线指导
- 安装调试视频
- 故障码查询
- 氟机选型
- 留言反馈
- 专业版切换
- 飞奕公众号
- 使用说明

原有工具功能和目标页面保持可用。从“我的”迁入的四项不再在“我的”重复出现。

### 3.3 我的 Tab

仅保留：

- 当前账号
- 版本信息
- 关于飞奕

删除暖通合伙人、企微客服；隐藏语言切换；删除留言反馈、专业版切换、飞奕公众号、使用说明入口。页面不显示会员、营销或教学内容。

## 4. 设备调试架构

所有型号遵循同一层级：

1. 连接设备。
2. 进入“快速配置”首页。
3. 首页完成高频现场配置和验证。
4. 可随时选择“跳过快速配置”，直接进入设备详情。
5. 次要参数和高级配置集中进入“更多设置”。

快速配置使用配置驱动的共享页面骨架：设备摘要、配置任务卡、完成状态、主操作和“更多设置”。不同产品族只配置任务集合、字段和目标页，不复制整套页面。

### 4.1 A01 / A02 / A03 室外机控制器

4 路 F、8 路 E 和 4G 版本共用交互模板，仅型号、通道数、联网能力和产品外观图不同。

快速配置：

1. 多通道空调品牌批量配置。
2. 服务器参数配置；保存后自动执行连通检测并显示检测中、成功或失败状态。
3. 电表参数下发。
4. 空调控制功能验证。

更多设置：通道独立配置、服务器高级参数、局域网、广域网、RS485/RTU、客户服务器、设备诊断、固件升级和设备信息。具体入口根据版本能力显隐，非 4G 版本不展示蜂窝网络参数。

### 4.2 F16G / B25LG 室内机型

两款产品共用室内机模板。服务器地址由设备固化，任何页面均不出现服务器配置入口。

快速配置：

1. 单路空调品牌设置。
2. 空调控制验证。
3. 固件升级。

更多设置：设备信息、空调高级参数、通信诊断和恢复默认设置。

### 4.3 S74G 单路室外网关

快速配置：

1. 单路空调品牌配置。
2. 服务器配置；保存后自动执行通讯检测。
3. 空调控制验证。

更多设置：服务器高级参数、网络参数、空调高级参数、设备诊断、固件升级和设备信息。所有页面均不出现电表配置或电表状态。

### 4.4 FD01G 分体机控制器

FD01G 保持独立交互模板，不出现服务器配置。功能逻辑以现有 FD01G 独立小程序原型为准。

快速配置：

1. 红外码库选型匹配：品牌搜索、热门品牌、码库选择、逐码测试与匹配确认。
2. 电流阈值设置。

更多设置：空调开关、模式、风速和温度验证，红外学习，电流检测及曲线，电压、功率因数、电流阈值、采样模式，固件与设备信息。

### 4.5 E50 空调诊断设备

E50 保持独立蓝牙和 4G 交互模板，以 `D:\workspace\E50小程序版 dev` 为功能参考。蓝牙和远程入口进入同一设备能力页，但连接方式和返回路径不同。

快速配置沿用 E50 主链路：连接状态、空调品牌选择、空调系统搜索、室外机与室内机识别。设备详情保留室外机参数、室内机列表及参数、空调控制、诊断和固件升级。删除操作指引、演示提示、冗长超时说明、抽屉中的营销入口和无关说明。

## 7. 状态与错误处理

- 扫描中：显示轻量动态状态和“刷新”。
- 无设备：显示“未发现设备”和“重新扫描”。
- 连接中：设备行锁定重复操作并显示“连接中”。
- 连接失败：显示“连接失败”和“重试”。
- 参数保存：显示“保存中 / 已保存 / 保存失败”。
- 服务器检测：显示“检测中 / 通讯正常 / 通讯失败”，失败时提供“重新检测”。
- 远程离线：仅显示“离线”，不允许进入调试。

所有反馈均为产品状态，不包含教学段落、过程解释或原型提示。

## 8. 验收标准

- 三 Tab 内容与迁移要求完全一致。
- 设备页无说明横幅、型号查找和现场工具模块。
- 蓝牙列表按型号聚合，可展开设备并进入对应调试页。
- 仅 E50 出现在 4G 远程列表，且 E50 同时支持蓝牙和远程入口。
- A01/A02/A03、F16G/B25LG、FD01G、S74G 的快速配置内容与能力边界正确。
- F16G/B25LG 不出现服务器配置；S74G 不出现电表功能；FD01G 不出现服务器配置。
- 全部型号支持跳过快速配置进入设备详情，并能从详情进入更多设置。
- 产品卡片均使用项目内产品外观图，优先符合飞奕 Logo 和 45 度视图规则。
- 全站不存在“演示环境”“原型”“阶段”“兜底入口”等交付外文案。
- 主要页面在 402 × 874 和常见移动端宽度下无横向溢出、遮挡或不可点击操作。
- 关键链路通过自动化浏览器检查和人工截图检查。
