# 飞奕网关调试原型二次迭代设计

## 1. 目标

在现有 D 版静态原型上完成第二轮覆盖改版。全站继续保留“设备、工具、我的”三 Tab，并以 E50 小程序工程的调试首页、列表、底部选择面板、左侧菜单和连接状态管理作为统一交互基准。

## 2. 手机画布与滚动

- 桌面预览使用 430 x 932 比例的大屏手机画布，最大占用浏览器可视区 96%，保持比例缩放。
- 在手机宽度下使用完整可视区，不显示外部阴影或边框。
- 状态栏、顶部导航和底部 Tab 固定在手机画布内；长内容只在内容区域上下滚动。
- 侧栏、底部面板、确认弹窗和 Toast 的定位范围均为手机画布，不覆盖画布外区域。

## 3. 设备首页

- 蓝牙页展示 A01F、A01E、A02FG、A02EG、A03FG、F16G、B25LG、FD01G、S74G、E50 共 10 个独立型号。
- 产品区每行两张卡片；卡片只显示产品外观图和型号。
- A01F、A01E、A02FG、A02EG、A03FG 分别使用 A01-4、A01-8、A02F、A02E、A03FG 对应产品图。
- 点击型号卡后，在该行下方展开通栏设备列表；设备名称、MAC、信号与连接按钮保持现有列表形式。
- 4G 远程页只显示 E50 设备列表。

## 4. 持续连接调试工作台

- 蓝牙连接状态写入浏览器会话存储，在快速配置、设备详情、空调管理和各设置页之间持续保留。
- 浏览器返回和页面顶部返回只负责页面导航，不断开连接。
- 蓝牙模式的左侧菜单底部提供“断开蓝牙连接”；二次确认后清除连接状态并回到设备首页。
- E50 从蓝牙模式切换到 4G 时，先弹出“切换后将断开蓝牙连接”的确认框；确认后切换为 4G 状态。
- E50 处于 4G 模式时不显示“退出远程调试”或“断开连接”入口。

## 5. 快速配置与设备详情

- 快速配置页删除“跳过快速配置”，仅保留“进入设备详情”。
- 设备详情是调试工作台首页，首屏展示当前设备连接、固件、网络、通道、服务器和运行参数。
- 低频参数和配置页面全部从左侧菜单进入，菜单在页面内滑出并保持当前连接状态。
- “空调控制验证”统一进入空调管理页，不再打开单一控制表单。

## 6. 型号能力

### A01F / A01E / A02FG / A02EG / A03FG

- 快速配置：多通道空调品牌配置、服务器配置与通讯检测、电表参数下发、空调管理。
- 多通道配置按通道逐项设置：启用/停用（默认启用）、空调品牌（含模拟器）、协议属性主/从（默认主）。品牌为模拟器时显示模拟器数量，范围 1-160。
- 服务器配置包含“服务器 IP 配置 / 服务器域名配置”双页签、启用状态、IP 或域名、端口、用户名、密码、发布主题、订阅主题、服务器类型和协议类型。
- 服务器类型：本地 TCP、云端 MQTT。协议类型至少包含 JSON、MODBUSTCP_V2.6、MODBUSTCPCLIENT_V2.6、MODBUSRTU_V2.6。

### F16G / B25LG

- 快速配置：单路空调品牌设置、空调管理、固件升级。
- 不展示服务器配置。

### S74G

- 快速配置：单路品牌配置、服务器配置与通讯检测、空调管理。
- 不展示电表功能。

### FD01G

- 快速配置：红外码库选型匹配、电流阈值设置。
- 专属页面按 FD01G 原型实现：空调管理、红外匹配、红外学习、电流检测、电量采集配置。
- 电量采集配置包含电压、电流、功率因数、电流阈值和采样模式；其余通用页面复用 A 系列工作台样式。

### E50

- 页面结构和视觉严格参考 E50 小程序工程：连接摘要、通讯模式、品牌选择、空调系统、室外机参数、内机列表、空调控制、诊断和升级。
- 品牌与通讯模式使用底部选择面板；调试功能通过左侧菜单访问。
- 空调管理按通道展示内机卡片，支持单选、多选、全选、单独控制、批量控制、全开和全关。

## 7. 错误与反馈

- 扫描、连接、保存、检测和控制使用简短状态反馈，不出现教学或原型说明文字。
- 服务器检测具有检测中、通讯正常、通讯失败三种状态。
- 断开连接和 E50 通讯模式切换使用确认弹窗，避免误操作。
- 无设备、离线、输入范围错误均提供明确但简短的产品状态。

## 8. 验收

- 大屏手机比例和内部滚动在桌面与移动端均正常。
- 10 个型号独立展示，产品首页为两列且卡片只有图片与型号。
- 快速配置无“跳过快速配置”。
- 左侧菜单、设备详情、空调管理、显式断开和 E50 蓝牙转 4G 均可完整操作。
- A 系列逐通道配置、服务器双页签、FD01G 差异功能和 E50 核心页面均可交互。
- 静态需求测试、UI 回归和浏览器冒烟测试全部通过。
